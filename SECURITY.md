# Security policy

Report suspected vulnerabilities privately to repository maintainers through GitHub private vulnerability reporting when available. Never include live secrets, children's information or customer material in a public issue.

The platform and runnable templates are local training environments. Host ports must bind to loopback. Public deployments require a separate authentication, authorisation and operational review. Browser quiz progress is not a trusted grading authority.

Run `.github/scripts/security_guard.py` before publication. See [privacy and publication policy](LEGAL_AND_PRIVACY_COMPLIANCE.md). Secret scanning covers selected patterns; passing checks does not certify complete security or legal compliance.
