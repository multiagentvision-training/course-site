# MultiagentVision Training — закрытый учебный сайт

Материалы зашифрованы (AES-256-GCM). Ученический и учительский коды разные: код группы не открывает кабинет учителя и не содержит спойлеров квиза. Без кода файлы в `data/` — случайные байты. Исходники курса — в приватном репозитории организации.

Курс содержит текстовые уроки, пояснения, квизы и стенды. Аудио, видео, субтитры и постеры удалены.
