# course-site — закрытый класс

**Стоп, если вы ищете Docker, `make up` или Postgres.** Вы в **аудитории с кодовым замком**, не на заводе. Стенд поднимают в [openvision-platform](https://github.com/multiagentvision-training/openvision-platform). Исходники уроков открытым текстом — в учебнике [program-curriculum](https://github.com/multiagentvision-training/program-curriculum). Если Git и «репозиторий» вы видели один раз — сначала энциклопедия [openvision-handbook](https://github.com/multiagentvision-training/openvision-handbook): читайте на GitHub, книгу не клонируют.

## Куда вы попали

Курс MultiagentVision Training кладёт уроки в четыре разных шкафа. Этот шкаф — **сейф**.

| Дверь | Репозиторий | Что происходит |
|---|---|---|
| Учебник | [program-curriculum](https://github.com/multiagentvision-training/program-curriculum) | Автор пишет уроки открытым текстом |
| **Класс (вы здесь)** | [course-site](https://github.com/multiagentvision-training/course-site) | Те же уроки **зашифрованы**. Вы вводите код доступа в браузере |
| Мастерская | [openvision-platform](https://github.com/multiagentvision-training/openvision-platform) | Вы клонируете и пишете код |
| Энциклопедия | [openvision-handbook](https://github.com/multiagentvision-training/openvision-handbook) | Вы понимаете слова до кнопок |

Репозиторий **публичный**: в git лежит только шифр. Уроки без кода доступа не читаются. Учебник и мастерская по-прежнему приватные.

Живая страница класса: [GitHub Pages](https://multiagentvision-training.github.io/course-site/). Код доступа выдаёт курс. **Код не кладут в git и не присылают в этот README.**

## Для человека, который только начинает

Вам не нужно понимать шифры. Вам нужно три факта:

1. **Без кода доступа** файлы в `data/` — случайные байты. Так задумано. Это не «сайт сломался» и не «надо поставить Docker».
2. **С кодом** браузер расшифровывает уроки **у вас на компьютере**. Код никуда не отправляется. В сборке нет вашего пароля открытым текстом — только соль и проверочный блок.
3. **Класс не запускает завод.** Здесь нет `Makefile` и нет `infra/compose.dev.yml`. Витрина `localhost:5173` появится только после `make up` **в мастерской**.

Прогулка по файлам: [глава encyclopedia](https://github.com/multiagentvision-training/openvision-handbook/blob/main/docs/09-walk-the-repos/walk-course-site.md). Первая минута кампуса: [вау encyclopedia](https://github.com/multiagentvision-training/openvision-handbook/blob/main/docs/00-before-install/first-minute-wow.md).

## Как открыть уроки (ученик)

1. Получите приглашение в организацию GitHub и код доступа от курса.
2. Откройте https://multiagentvision-training.github.io/course-site/ (или этот репозиторий → GitHub Pages).
3. Введите код. Расшифровка — только в вашем браузере.
4. Смотрите неделю, проходите квиз. Команды из урока запускайте **в папке мастерской**, не «в этом репозитории».

Если уроки не открываются:

| Что видите | Что это обычно значит | Чего не делать |
|---|---|---|
| 404 на github.com | нет доступа в org | не ставить Docker |
| Страница есть, уроки — каша / ошибка кода | нет кода, опечатка, или код от **старой** сборки | не «чинить шифр» |
| `data/*.enc` в редакторе — мусор | без расшифровки так и должно быть | не переименовывать в `.md` |
| Ищете Postgres / `make up` | вы не в мастерской | открыть openvision-platform |

После смены кода ментором старый код перестаёт подходить сразу: нужна новая сборка сайта.

## Что лежит в репозитории

Мало файлов — это признак класса, не «пустой проект».

| Файл | Зачем новичку |
|---|---|
| `README.md` | табличка на сейфе (вы её читаете) |
| `index.html` | каркас страницы |
| `app.js` | просмотрщик: код доступа, расшифровка, меню недель |
| `lab.js` | лаборатории урока |
| `style.css` | внешний вид |
| `marked.min.js` | рисует Markdown в браузере |
| `manifest.json` | оглавление: какая неделя какими `.enc` файлами собрана |
| `data/*.enc` | уроки, озвучка, лабы, видео — шум без кода |
| `data/verifier.bin` | проверка кода без хранения самого кода |

Как устроено технически (можно отложить): ключ получается из кода доступа через PBKDF2, уроки закрыты AES-256-GCM. Сборщик живёт в учебнике (`tools/course/build_static_site.py`), не здесь. Ученик недели 1 сюда ничего не пушит.

## Чего не делать

- Не клонировать этот репозиторий «чтобы запустить курс». Класс смотрят в браузере.
- Не ставить Docker, Python, MkDocs ради этого шкафа.
- Не коммитить код доступа.
- Не путать этот сайт с витриной завода `http://localhost:5173`.
- Не ждать, что открытый `data/w01-lesson.md.enc` станет читаемым уроком в VS Code без кода.

## Как связано с остальным курсом

Автор пишет урок в учебнике → сборщик шифрует и публикует **сюда** → вы смотрите в браузере → практику делаете веткой в мастерской → слова, которые пугают, разбирает encyclopedia.

16 недель обязательны, 17–24 — факультатив. Это расписание учебника, не этого сейфа: здесь лежат зашифрованные копии. Карта «что появляется на заводе» — в encyclopedia: [16 недель — один стенд](https://github.com/multiagentvision-training/openvision-handbook/blob/main/docs/02-big-picture/sixteen-weeks-one-stand.md). Открытые тексты уроков — в [program-curriculum](https://github.com/multiagentvision-training/program-curriculum).
